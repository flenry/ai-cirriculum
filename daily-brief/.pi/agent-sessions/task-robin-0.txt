## Problem
`pnpm brief` crashes on startup with `SQLITE_ERROR: no such table: briefs` because `createDb()` never runs any DDL. The briefs table doesn't exist on a fresh install.

## Your Job
Apply the fix. Write the code. Make it work.

## Files to Read First
- src/db/client.ts
- src/db/schema.ts
- src/index.ts
- CLAUDE.md

## Exact Changes to Make

### Change 1 — src/db/client.ts
Replace the entire file with:

```ts
import { createClient } from '@libsql/client';
import { drizzle } from 'drizzle-orm/libsql';
import { mkdirSync } from 'fs';
import { dirname } from 'path';

export async function createDb(dbPath: string) {
  if (dbPath !== ':memory:') {
    mkdirSync(dirname(dbPath), { recursive: true });
  }
  const client = createClient({
    url: dbPath === ':memory:' ? ':memory:' : 'file:' + dbPath,
  });
  await client.execute(`
    CREATE TABLE IF NOT EXISTS briefs (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      generated_at TEXT NOT NULL,
      weather_json TEXT,
      hn_json TEXT,
      github_json TEXT,
      wikipedia_json TEXT,
      status_json TEXT NOT NULL
    )
  `);
  return drizzle(client);
}

export type DrizzleDb = Awaited<ReturnType<typeof createDb>>;
```

IMPORTANT: Read src/db/schema.ts first to confirm the exact column names match what Drizzle expects.
