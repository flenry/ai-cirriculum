Description: A personal daily brief generator that pulls weather, top HN stories, GitHub notifications, and a random Wikipedia article. Renders as terminal output (chalk) and HTML file. Runs on a cron schedule. Stores last 30 days of briefs in SQLite.

1. **OpenWeatherMap** — current weather by city/coords. Free tier limits, auth (API key), endpoint, response shape.

3. **GitHub Notifications** — personal notifications API. Auth (PAT), endpoint, response shape, rate limits.
4. **Wikipedia Random** — random article endpoint. No auth, response shape, how to get a summary.

## Technical Areas to Map
- SQLite schema: storing 30 days of briefs (what to store, how to prune)
- Cron scheduling: node-cron vs cron vs system cron — which fits best for a TypeScript project with env-var-configurable time
- Terminal rendering: chalk options, structured layout
- HTML rendering: lightweight templating (no framework) for clean email-style HTML output
- Mocking strategy: how to mock all 4 APIs in Vitest with zero real network hits

## Must-Haves (from PLAN.md)
- Fetch from 4 live APIs: OpenWeatherMap, HN Algolia, GitHub notifications, Wikipedia random
- Render as terminal output (chalk) and HTML file
- Schedule via cron — configurable time via env var
- Store last 30 days of briefs in SQLite
- All external API calls mocked in tests — zero real network hits in test suite
